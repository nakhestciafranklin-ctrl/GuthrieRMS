# Guthrie RMS Foundation Freeze

This version should be treated as the foundation build before real data entry.

Core modules included:
- PIN login
- Student/teacher/manager access
- Clock in/out
- Dining room orders
- Counter and To-Go orders
- KMS and BOH station screens
- Checkout and refunds
- Catering and invoices
- Inventory and vendor ordering
- Reports and exports
- Student development tracking

Next work should be bug fixes, training, and real-data setup before adding new feature families.
