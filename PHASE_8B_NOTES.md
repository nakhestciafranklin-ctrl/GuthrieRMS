# Phase 8B Notes

## Production Mode
Manager Setup now has a Demo Mode toggle. Turning Demo Mode off hides demo login help from the main PIN page.

## Bistro Menu Growth
Managers can add new Bistro menu items and separate them into:
- Entree
- Beverage
- Dessert

## Daily Production Pars
Each Bistro menu item can be assigned a starting par at the beginning of service. The POS displays remaining quantity and prevents ordering when the item is 86'd.

## 86 System
Items are 86'd automatically when quantity reaches zero. Managers may also manually 86 an item and record a reason.

## Export Fix
CSV export now supports both array-based reports and object-based reports, fixing the broken export buttons.
