# Phase 8C Notes

This update restores recipe entry so culinary labs can be connected to real inventory usage.

## Recipe Fields
- Recipe name
- Yield quantity
- Yield unit
- Inventory source
- Ingredient inventory item
- Quantity
- Unit
- Prep notes
- Method/lab notes

## Lab Inventory Deduction
Teachers or managers can choose a saved recipe, enter a lab/class name and multiplier, and deduct ingredients from Culinary Department Inventory.

## Teacher Student Tracking
Teachers can use Student Development to view assigned students, position history, workforce hours, skill growth, and evaluations.
