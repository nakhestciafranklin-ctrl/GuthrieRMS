BriskTable POS add-on for iPads

Groups items under section bars (Breakfast, Entrées, Sides, Bakery & Desserts, Drinks, Catering) on the BriskTable POS screen, and shrinks item photos so BriskTable accepts them. It changes nothing in BriskTable's own settings.

Without the add-on, BriskTable lists items alphabetically with no sections. Set it up on every iPad that takes orders.

Option 1 (recommended): Userscripts app — works automatically

One-time setup per iPad, about 3 minutes.

  1. Install the free Userscripts app from the App Store (by Justin Wasack), and open it once.
  2. Go to Settings → Apps → Safari → Extensions → Userscripts, turn it on, and set All Websites (or www.brisktable.com) to Allow.
  3. In Safari, open this page and tap Install add-on below. Tap the puzzle-piece / AA icon in the address bar, choose Userscripts, and tap Install.
  4. Open the BriskTable POS. The sections appear on their own every time.

Already installed? Userscripts picks up new versions on its own; to update right away, tap Install add-on again.

Install add-on

Option 2: Bookmark — no app needed

Tap the bookmark each time the POS screen is opened or reloaded.

  1. Tap Copy bookmark code.
  2. In Safari, bookmark any page (Share → Add Bookmark), name it RMS POS add-on, and save.
  3. Open Bookmarks, tap Edit, tap the new bookmark, clear its address and paste the copied code. Tap Done.
  4. Open the BriskTable POS, sign in, then tap the RMS POS add-on bookmark.

Using it

  1. Tap the items, then tap Add Notes and type the guest's name. Pick Takeout / Counter / To-Go / a table.
  2. Tap Submit order or Checkout. The note stays with the order.
  3. Item photos: in BriskTable go to POS Setup → Products, tap an item, tap +Add an image and take or choose a photo, then Save. With the add-on, any photo is shrunk to fit automatically (BriskTable alone refuses photos over 500 KB). The photo shows on the item's tile in the POS.
  4. To move an item to another section, edit its Description in BriskTable (Point of Sale → Products) to one of: Breakfast, Entrées, Sides, Bakery & Desserts, Drinks, Catering.
